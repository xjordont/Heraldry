# Hero Record (illustrated, two sides)

One US Letter sheet printed front and back, 816 x 1056 CSS px (8.5 x 11 in). Owner-directed design, 2026-10-26.

| File | Purpose |
|---|---|
| `sheet.py` | The one generator: `blank` rewrites the two blank sides; `heroes` fills them for the 24 Basic Mode Heroes |
| `parts/front.html`, `parts/reverse.html` | Static artwork and lettering; every ledger, field and value is generated around them |
| `sheet.css` | Shared type, fonts (`fonts/static/`), and classes |
| `hero-record-front.html`, `hero-record-reverse.html` | The blank sides, generated by `sheet.py blank` (do not edit by hand) |
| `art/` | Ink art and traced ornaments (SVG; the three illustrations are 4x upscaled PNGs, about 490 to 540 ppi at print size); `hr-shield5-mask.png` masks portraits to the shield field |
| `previews/` | 300 dpi renders of the blank (`sheet.py blank --png`) |

```sh
python3 assets/hero-record/sheet.py blank --png
python3 assets/hero-record/sheet.py heroes --pdf build/hero-records/basic-heroes.pdf
```

Type follows `config/design_tokens.json`: Grenze Gotisch (titles and banners), Source Serif 4 Bold (product line, resource headings, identity values), Source Sans 3 (labels, attribute values, filled text). Every printed label and value is 9 pt or larger.

## Front

- Identity cartouches (Name, Class, Ancestry, Background), Level, and a portrait field.
- Attribute shields. Values are centred on each white field's optical centre in the shield headings' face (Source Sans 3 Bold). DEX and SPD show the effective value: the top of the field carries the base (blank: "Base ___"; populated DEX: base and the worse equipped DEX Pen, for example "+2 − 3" over "−1"; SPD: "Base 7"" over the lowest of base SPD and every equipped Max Speed).
- Hit Points, Energy, Luck (maximums printed, current left for play), Armour, Wounds, Weapons (no P/O column), Inventory, and Coins. The starting coins run along the inside top of the Coins ring ("Start ___" on the blank); the rest of the field is for the current total.

## Reverse

- Heroes with Powers: Powers (Tier, Cost, Range broken out) and Talents & Special Abilities, 14 rows each.
- Purely martial Heroes (no Powers): the reverse is titled "Talents & Abilities" and Talents & Special Abilities fill the whole page.
- Every word of each ancestry trait, background rule, talent, Power and special rule prints at 9 pt, two text lines per ruled row, ruled between entries. Weapon trait rules are universal rules and are not repeated (owner decision 2026-10-26); the Weapons table names every trait. Senses restate a brief rule (for example "Within 12", ignore Cover and visual penalties from nonmagical Darkness. Does not reveal Hidden or Invisible combatants; magical Darkness still applies.").
- If Talents overflow, an ability with an AP cost moves into spare Powers rows.
- Mossgrave's Wild Shape Form Rules and Novice Beast Forms print on a separate one-third-page card (owner decision 2026-10-26); his sheet points to it.

## Populated Heroes

`sheet.py heroes` reads `typst/heroes/basic-heroes.json` (B.4 of the active manuscript; refresh it with `python tools/hero_cards.py extract`). Every listed item and the Hero's starting **Coins** (RC514) print on the sheet: armour in Armour, weapons in Weapons (carried-only items marked), everything else in Inventory with its full text. Portraits (`assets/art/ink/<art>.png`) are centred on their own ink in the shield field and masked to it.

Output goes to `build/hero-records/` and is never committed (docs/LARGE_FILES.md): each Hero's front and reverse in B.4 order, then any reference cards, so duplex pairs stay aligned. The build fails if any text overflows its cell, falls below 9 pt, or if any B.4 rules text, item, or coin value is missing from a Hero's pages.

Print actual size (100%), Letter portrait, duplex, flip on the long edge. Do not commit PDFs; publish through a GitHub Release. Owner approval of this version and physical print, handwriting, and duplex registration are **NOT TESTED**.
