# Delivered native artwork

Every delivered illustration, saved unchanged by the art worker as `<ID>.<png|jpg|webp>` and stored with Git LFS, plus the twelve original atmospheric masters made in ChatGPT Work on 2026-10-07 (ART-COVER-001 and ART-CH01-001 through ART-CH11-001). Keep these originals unchanged. The book places approved images through their ink derivatives in `assets/art/ink/`; the cover and chapter openers fall back to the twelve masters only while their `-002` replacements are unapproved.

Fetch only the files a task needs, for example `git lfs pull --include="assets/art/incoming/ART-COVER-001.png" --exclude=""`; `python tools/check_art.py` checks the twelve masters. Their provenance and native-size limits are in `production/art/ART_MANIFEST.json` and `production/art/PROMPTS.json` (history in `docs/history/ART_HANDOFF.md`). Current approvals are in `production/art/SELECTIONS.json`; the pipeline is in `docs/ART_AUTOMATION.md`. Rules and deployment diagrams remain separate editable vectors.
