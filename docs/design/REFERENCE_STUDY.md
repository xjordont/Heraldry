# Reference study, 2026-10-12 (all ten owner-selected books)

Two design workers mapped every page of the ten reference PDFs on contact sheets and inspected about 90 representative pages closely. Page numbers are 1-based PDF viewer pages (TNA and The Village Hunt are spread-format, numbered by spread). Sizes are visual estimates. These are design observations for original Heraldry decisions; nothing here is copied into the book. The resulting decisions are in `docs/BOOK_DESIGN_PLAN.md`.

## Part A: systematic rules references (Mythras, Five Leagues, Hametsu, TES Call to Arms, TNA)

### workerA reference study (rules-reference books)
Inspected: contact sheets of every page of all five books (workerA/<book>/sheetNN.png) plus close renders (workerA/<book>/p-*.png, pair*/tri*.png). Pages not listed were seen only at thumbnail scale. Page numbers = PDF page index. TNA PDF pages are 2-up spreads (Letter x2, 1224x792 pt), so spread N = book pages 2N-2 / 2N-1 in print numbering; I quote PDF spread index.

## 1. Mythras Classic Fantasy Imperative (157 pp, 8.35x11 in, B&W interior)
(a) Page types: cover 1; credits/contents 2; legal 3-4; character sheet 5, 13; chapter openers w/ wide grayscale banner + blackletter-ish title 3, 6, 16, 25, 64, 73, 87, 144; ordinary 2-col text 7-9, 74-80; tables 7, 10-15, 63, 67-70, 85; full-width art spreads 20, 66, 86; spell entries 121-142; monster profiles 144-149; magic item list 150+; index at back.
(b) Lessons
- 6, 63, 81, 84: running head top-left/right in small caps, with a thick+thin double rule beneath; same double rule closes page above folio. Strong "ink" frame with zero perimeter box. Steal the double rule.
- 6, 63: table header = solid black bar with reversed white bold serif, thin rule rows, centred cells, ample row padding (about 0.28 in). Table titles in the display face, left-aligned above table. Very readable in pure black ink.
- 84: table sits in the right column beside the topic text; footnotes (*, **) in smaller type directly under; tables are column-width, not page-width.
- 3 vs 63: chapter opener = full-measure grayscale art band with huge display title overprinted white/black, then a drop cap in first paragraph. 
- 81, 84: cut-out line-art figure bleeds into the text column and body text wraps around its silhouette; makes the book feel crafted. Wrap needs manual care (81 wrap is ragged, slightly amateur).
- 124-127: spell entry = display-face name, italic parenthetical school, italic bold single stat line (Rank, Cost, Area, Casting Time, Duration, Range, Resist), then prose. Compact and scannable; 2 cols, up to 6 entries/page.
- 144-145: monster profile = display name + rank, then a run of short labelled paragraphs (STR..., Alignment, Combat Skill, Skills, Armor, Hit Points per location). No box; relies on heading + labels. Dense and plain; Heraldry should box and tabulate this.
- 81: special effects as bold-italic run-in terms (Marksman: ...). Good for keyword glossaries.
(c) Avoid: orphaned headings at column bottoms; page 80/79 tables mid-column with tiny type; wrap with ragged edges; uniform text walls on 74-76 with no examples/callouts; display-face used for small subheads is slightly tiring.
(d) Principles: double-rule top/bottom frame; black-bar reversed table header; right-column table with footnote lines; drop cap + art band openers; one-line italic stat-line for entries.

## 2. Five Leagues from the Borderlands 3rd Ed (236 pp, 6.14x9.21 in, colour)
(a) Types: cover 1; credits 4; contents (3 cols) 5-6; part opener full-bleed art 7, 15, 93; intro 8-14; characters 16-30; flowchart "Many Roads" 92; scenario/table pages 94-125; Enemy section (profile tables) 181-188; Resolution 189+; XP/loot 195-199; enemy plans 209+; sheets/tracking at back.
(b) Lessons
- 91-120, 181-210 sheets: each Part has its own accent colour (red/purple/blue/green/teal) applied to running head banner, headings, table headers, folio tab. Navigation is obvious from a thumbnail. In ink: translate to 5 distinct running-head icon/ornament motifs, or tint-free tab glyphs.
- 5, 16, 92: running head = centred condensed small-caps title flanked by long ornamental rapier-like dividers; thin inner border with tiny corner ornaments at 0.4 in. Elegant but is a perimeter frame (Heraldry must not copy; use head ornament only).
- 5: contents in 3 columns; section bands (solid colour with white caps + page no.), subsections as indented items with dot leaders, italics for third level. Dense yet legible: 3 hierarchy levels.
- 92: whole-campaign flowchart in boxes with step lists and page refs; arrows in section colour. Model for Heraldry "turn / campaign sequence" diagram.
- 102, 187: d100 tables with 2-3 col, tinted header row, alternating 1 pt hairlines, roll column left narrow. Wide tables go full page width (187 sideways rows with "Traits:" sub-row spanning columns) — a great trick for long text in tables: put long text in a spanning second row.
- 195: rules in 2 columns, "term + indented value" pairs for XP awards; tables with green banding. Clean.
- 16: Subheads in italic colour serif, body ~9.5 pt on 6x9 page, 1 col + side column with small art.
- 98/108: rule callout in red-outlined box with shadow tag "Optional/Example" (small, 1 per page).
(c) Avoid: five bright colours; ornate frame on every page; contrast of thin hairline table rules in colour at small size; tiny sheets (sheet pages 230+).
(d) Principles: section identity via header glyph; contents with 3 weights; spanning sub-row inside wide tables; a campaign-flow diagram as an orientation page.

## 3. Hametsu 2nd printing (183 pp, 7.6x10 in, heavy colour + dark pages)
(a) Types: cover 1; lore pages full-bleed dark art w/ text panel 5-17; contents 8-9; rules pages light grey paper w/ red side tab 19-35, 87-90; class "Path of Legend" spreads red-black 61-85, 151-173; equipment/weapons tables 72-73, 160-161; scenario generator tables 86-90; story/scenario 154-157; hunter sheet 176; index 178.
(b) Lessons
- 23, 29: a dark sidebar column (about 1/4 page, full height) holds Designer's Note / Example in italic reversed type; main text stays in clean light column. Strong separation of rules vs examples. In ink: a solid black or ruled right-hand margin column for Examples.
- 72, 90: tables with letterspaced bold caps header, heavy black rule under header, alternate row pink banding; row text left-aligned for long cells (90 uses 5 columns for rule text, width 100%). Banding translates to light grey screen.
- 90: dice-roll d6 table as the anatomy of a procedure (Name, Group, Info, Placement, Activity); long prose is permitted in cells at ~8 pt; readable because rows have 0.15 in padding.
- 23: in-line table (D6 row) plus decorative divider ornament; small ornaments only between sections.
- 178: index, 4 columns, big initial letters as separators, dot-free page-number right alignment. Very compact; best index in my set.
- 176: character sheet with thick rounded-corner boxes, display-face field labels; copying style only for sheets.
- Headings 23-29: condensed brush-like display face, underlined; consistent.
(c) Avoid: red wash noise behind text (22-23 splatter), brush-title pages with red/black full bleed (62-85): unreadable level lists, tiny 7 pt text on dark panels; 5-17 white text on dark art. Folio circles with ornaments heavy. Not black-ink friendly.
(d) Principles: marginal example column; header letterspaced caps over heavy rule; index with big letter heads; shaded alternating rows; 5-col procedural table.

## 4. TES: Call to Arms core (136 pp, 6.5x9.5 in, parchment)
(a) Types: cover 1; credits 2; contents 3; chapter openers with banner 4, 23, 26, 61, 69, 85; photo-heavy example pages 6-7; gameplay summary 8-9; rules w/ diagram 11, 27-29; cards 12-14; adversary AI flowcharts 73-83; special rules glossary 85-102; scenario rules; appendices A-G 127-135 (Tokens Index, Icons Index, Index, Quick Reference 131, Cards, Pre-Game, Template); back cover 136.

- 11: LoS diagrams: three stacked figures each with black caption bar at bottom-left corner with reversed small caps caption, text column beside. Caption bar attached to figure = legend kept together. Map figure 27 numbered pins 1-4 with legend in caption bar listing numbered measurements.
- 27: Boost callout boxes: pale blue panel w/ tinted heading strip, centred caps title, diamond bullets. A "keyword box" idiom for ability lists.

- 128: Icons Index in 2 cols with icon left, name, page right; categories as bold lead-ins. 131 Quick Reference: black header bar, columns ICON | NAME | EFFECT | DESCRIPTION, alternate shading, rows 0.45 in tall.

## 5. Tanares Adventures Ultimate Rulebook (43 spreads, 2 x Letter, colour)
(a) Types: cover 1; credits + contents 2 (3-col); component overview 3; intro 4; Part I Combat opener 5, 10; set-up/anatomy 6; examples with grids 9, 18; rules 7-17; Part II Campaign opener 21; city phase 22-26; Part III appendices 35-42; glossary tables 36; special effects table 36; index 43.
(b) Lessons
- 2: contents spread-wide: 3 columns of dotted-leader entries, Part headings as solid bar (red) with white caps, chapter headings bold, 3 levels. Complete and compact; great for 400-entry rulebook.
- 6: "Table Setup" anatomy: components lettered A-Q in rounded bubbles on image, legend in 2 cream boxes on left, grouped by chapter. A model for stat card/unit profile legend.
- 18: worked example "A very difficult example": step-numbered 1.1, 1.2 … in a boxed column, with grid diagrams interleaved; path diagrams drawn as coloured lines on grid. Numbered substeps keep example synchronized with figures — adopt as numbering convention. Optional rule goes into a tinted separate box.
- 36 ("Numbers"/"Squares and Spaces", Appendix D Effects): glossary tables with 2 columns Word/Expression | Explanation, small-caps header row in red, row banding, example sentences in blue italic inside the explanation cell. Width = the whole page column, so long rules get 80% width. Effects table has icon column left.
- Top pages: three-column body grid on Letter, 0.35 in gutters, boxed sidebars with rounded corners and drop shadow; art bleeds off bottom (pages 6, 34 etc.) behind a washed gradient.
- Hierarchy: Part banner (blackletter, red), Chapter heading in caps, subhead small caps rule, run-in bold terms. Footers: small left/right running text + page.
(c) Avoid: busy gradients and glow at page bottoms (6, 34, 70), digital-looking drop shadows; full colour; text on parchment texture; art interrupts rules at page foot; about 7-8 pt text everywhere.
(d) Principles: use dotted-leader contents with 3 levels; numbered worked examples locked to figures; two-column Word/Explanation glossary with italic sample sentences; legend boxes keyed to lettered figure.

## Part B: atmospheric references (Deth Wizards, BlackDeathCity, Hellcrawl, Dread Nights, The Village Hunt)

### workerB reference study (Deth Wizards, Black Death City, Hellcrawl, Dread Nights, Village Hunt)
Inspected: contact sheets of every page of all five books; 70-90 dpi renders of ~14/12/12/22/11 pages (listed per book). Measurements are visual estimates.

## 1. Deth Wizards (108pp, Letter, B/W ink on grey mottled paper + splatter)
(a) Map: 1 cover (full-colour acid green, blackletter title); 2 title; 3 contents; 4-6 illustrated narrative fiction pages (large sans-italic text wrapped around full-height ink vignette); 7,13,41,53,91 chapter openers (huge blackletter title spanning 2-3 lines, staggered, splatter top, line-art skeleton/reaper cut-out, drop-cap in black square); 8-12 glossary/rules/example; 15-20 Legacy pages (boxed "Unique Power" sidebar + half-page painted ink figure bled to page edge); 21-22 list table (Necromantic Minion list); 23-30 minion profiles; 31-40 power lists; 46-52 combat with full-height wash illustration, text wraps; 54-62 scenario generator; 64-69 hero profiles; 70-84 scenarios (each = text block + small sketch map box + illustration); 85-89 optional rules; 91-103 post-game; 104-106 rules summary; 107-108 notes.
(b) Lessons: 
1. Chapter openers p7/13/41/91: one monumental blackletter title (approx 35-40% of page width per line, 2-3 lines, offset right on 2nd line) over generous empty top 1/3, then body in the lower half; title is the only decoration needed. Premium and unmistakable.
2. p4/p5: narrative "flavour" pages set in a larger, looser sans/italic with hard ragged-right and an ink vignette hugging the text edge: mood pages that carry zero rules, so legibility is a non-issue.
3. p22: table done as pure hairline rules: thick top/bottom rule, thin row rules, display face for header and entries, generous leading (about 2x text), no fills; marginal note in a narrow column to the right, small ornament skull bottom. Elegant table with zero ink fill.
4. p15: sidebar "Unique Power" in a left box with only a heavy top-left corner rule and a thin outline; text wraps around it. Stat line format `Rating | Type | Movement` on one line with pipes, bold labels (p64-66): compact profile anatomy, inline bold labels, no grid.
5. p72: scenario page = title, Difficulty|Players line, labelled mini-sections in bold-run-in style (Terrain/Heroes/Victory/Rewards/Advanced), sketch map in a plain box, big figure bleeding off lower right with text wrapped to its silhouette. Art lives in the lower-outer corner and the text column is shortened to suit.
6. p46/p48: full-bleed-right wash art with fading edges; text wraps in staggered measure.
7. Text sizes: body approx 9.5-10 pt serif, leading ~1.25, single column with ~0.7-0.9in outer margins, justified on opener pages and ragged-left in sidebars.
(c) Avoid: mottled grey parchment with noisy splatter (every page, esp. p57-69) lowers contrast and would burn ink; wrapped text around irregular art (p46, p48) creates very uneven lines and rivers; body tiny against the huge titles (p7) - jarring jump; long un-sectioned scenario text (p80-84); many unbalanced half-empty pages.
(d) Steal: single mega-blackletter opener with empty top third; art always bleeds off ONE outer edge; sidebars have a weighted corner, no fill; tables use rules and display-face entries only; narrative pages in larger italic with a vignette.

## 2. Black Death City playtest v1.01 (134pp, A4, black/grey halftone-wash on white with soft ink-edge vignette)
(a) Map: 1 cover (heraldic shield-and-banner emblem, blackletter title); 2 epigraph; 3-7 intro/factions/how-to-use; 8,18,34,48 chapter openers (tall black banner down the left edge with white "Chapter One" and an arrow, blackletter title top right); 9-17 core rules (2 col, boxed diagrams, icon diamonds, equipment spread p14 with big weapon art bleeding off bottom); 19-30 battle rules; 31-33 spells (Arcane Action with portrait top-left, table in column); 36-47 SCENARIOS (p36, 44 etc.: scenario name in blackletter, italic strapline, 3 columns "Before the Battle / During the Battle / Campaign" under black pennant headers, full-width map box at bottom with entry points and templates); 52, 72, 92, 112 warband openers (full-black left panel 40% width with shield, reversed white text; right: huge blackletter name); 55/75/96/116 fighter list (tall sword art left, boxed lists); 56-71 scrolls; 77 armoury (multi-box lists); 131-133 roster sheets; 134 back "To be continued" skull.
(b) Lessons:
1. p36/p44 scenario layout is the best map-page in the set: strapline, then three narrow columns with black pennant headers, labelled run-in bold small caps sub-heads (THE TWIST, DEPLOYMENT), a map at the foot in a double-ruled box with a small diamond ornament on the top rule and compass-labelled entry points. All needed info above the fold; map never overlaps text.
2. p66/p68 fighter scroll: ruled box; diamond icon top-left; blackletter name centred; italic keyword line; one-row black-header stat bar (Move/Blade/Bow/...) with white labels; two columns Wargear | Special Rules; italic quote at foot; tiny cross ornament centred on the bottom rule. Perfect stat-block anatomy; 3 per page with equal heights.
3. p8 banner: black ribbon with notched bottom as chapter marker; it doubles as a navigation device. Only one chapter number art per section, no clip art.
4. p52: reversed-out black left panel (shield art + white serif italic) is the faction opener; contrast with white pages gives rhythm without parchment. NOTE ink cost.
5. p11/p14 art: vignette matte edges (soft drift into white) rather than boxes; figure cut-outs on white; weapon art bleeding off bottom edge as a divider; very restrained.
6. p10, p13 icon-labelled diagrams (diamond slots linked by lines to a miniature) = readable rules diagram in ink.
7. p31 tables: header row black bar with white text, cells ruled in hairlines, first column narrow numbers; table sits in column width, bold run-in result titles inside cells.
8. Headings: 3 levels: blackletter display (H1), UPPERCASE bold serif (H2, ~11pt), bold-italic run-in (H3); body ~8.5-9pt serif, tight - slightly small.
9. Background: pale grey-white vignette; edges lightly darkened (all pages). Mood without a texture inside text area.
(c) Avoid: A4 body type is small (~8pt) with 3 narrow columns of ~1.6in (p36) - cramped ragged lines; grey cloud edge darkening is heavy on ink and band-prone; blackletter used for every name incl. long ones (p66 Guild Mercenaries Fighter Scrolls) - hard to read; icon diamonds repeated everywhere become wallpaper.
(d) Steal: pennant section header (black ribbon) with white blackletter; stat bar as one black row; scenario page = strapline + 3 labelled phases + map-in-ruled-box; chapter ribbon on outer edge for navigation; art as matte vignette bleeding off one edge.

## 3. Hellcrawl (109pp, Letter, full-colour modern OSR, cream paper, oxblood red + saturated illustration)

(b) Lessons:
1. p22/p40/p48: every location entry is a self-contained single page: numeral+title top-left, 2 sentence hook, ONE table. Fits the "whole entry on a page" rule; table has dark header bar (all caps small) + lighter rows + number ranges in a narrow left column ("11-15").

## Cross-book principles for Heraldry (ink, cream, no heavy texture)
1. Display type does the mood: one blackletter-like display face, used only for H1/openers and unit names, never body or table cells.
2. Keep reading area clean; put atmosphere in the outer margin/bottom third as ink vignette with matte-fade edges (Black Death City p11/14; Hellcrawl p64 proportion).
3. One consistent profile box (BDC p66) and one entry-per-page template (Hellcrawl p22).
4. Scenario = strapline, three labelled phases, map in ruled box, legend inside.
5. Reverse-black panels reserved for 1-2 openers; none on rules pages.
6. Flow-chart pills for any decision procedure.
7. Body at >=9pt; none of these books' 6-7pt table text.
