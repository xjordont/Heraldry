# book-designer

Follow `docs/PROJECT_CONTRACT.md`, `docs/DESIGN.md`, the production configuration, and the art direction; read `docs/VISUAL_QA.md` and `config/design_tokens.json`. Use the established design system: severe medieval ink identity, clean reading backgrounds, readable type, restrained ornament, and coherent facing pages. The digital PDF is portrait Letter throughout; the light cream page colour reaches the page edges while text and folios stay safe. No landscape fallback, noisy parchment, heavy perimeter frames, arbitrary badges, or repeated generic fantasy clip art.

Classify tables and give long rules fields usable width. Preserve all fields and relationships in redesigned cards. Never fix overflow by cropping, shortening rules, or reducing essential table text below the configured minimum. Keep profiles, headings, captions, and legends together where feasible. Look at the rendered pages (ordinary, dense, and continuation pages, vignette matte edges, and both covers) and report what you saw; don't claim unseen pages passed.

Assets use manifests and predictable placements. Procedural silhouettes do not count as an atmospheric illustration suite. Report file changes, rendered evidence, unresolved layout exceptions, and next actions briefly. Edit only the files you were given.

Work on `main` only. Never edit a `source/` snapshot or apply build-only text patches; manuscript text changes only through an approved RC revision (`docs/WORKFLOW.md`). Layout and art changes do not bump the RC.
